# TCS Company Valuation Project
• Developed a comprehensive financial forecasting model incorporating historical P&L, Balance Sheet, Cash Flow, working capital, Capex, and 5-year projections to evaluate business performance and financial drivers.
• Conducted DCF valuation, WACC analysis, Comparable Company Analysis (EV/EBITDA & EV/Revenue), and sensitivity analysis to assess enterprise value, equity value, and the impact of key valuation assumptions.
